# Hoja de vida personal

Sitio web personal desarrollado como proyecto de aprendizaje de HTML y CSS en Campuslands. El sitio presenta mi perfil profesional, formación académica, habilidades, experiencia laboral, proyectos e información de contacto.

## 🌐 Sitio publicado

[Ver mi hoja de vida](https://edu-gam.github.io/hoja-de-vida/)

> Reemplaza la dirección anterior por el enlace real de tu sitio publicado en GitHub Pages.

## 🎨 Diseño y mockup

El diseño se basa en una propuesta visual de estilo moderno y minimalista, con una paleta de colores azul y blanco, tipografía legible y una distribución organizada de la información.

El objetivo es presentar la información profesional de manera clara, manteniendo una experiencia de navegación sencilla.

![Mockup del diseño de la hoja de vida](docs/mockup/Mockup Hoja de Vida.png)

## 🖥️ Vista en computador

La versión de escritorio permite consultar las diferentes secciones de la hoja de vida mediante el menú de navegación. El contenido está organizado para facilitar la lectura del perfil, la formación académica, las habilidades y la experiencia laboral.

(docs/capturas/evidencia pc.png)

## 📱 Vista en celular

El sitio utiliza CSS adaptable para ajustar la distribución del contenido a pantallas pequeñas. Se busca mantener la legibilidad del texto, la visualización de la fotografía y el acceso al menú de navegación.

(docs/img/evidencia movil.png)

## 📂 Estructura del proyecto

- `index.html`: página principal con la hoja de vida.
- `proyectos.html`: página con los proyectos personales.
- `contacto.html`: página con la información de contacto.
- `styles.css`: estilos visuales y adaptación a diferentes tamaños de pantalla.
- `img/`: carpeta con la fotografía de perfil y otros recursos gráficos.
- `mockup/`: capturas del mockup y evidencias visuales del funcionamiento del sitio.
- `capturas/`: capturas de funcionamiento de la página en celular y computador.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño, colores, tipografía, distribución y adaptación a diferentes pantallas.
- **Git:** control de versiones del proyecto.
- **GitHub:** almacenamiento del código fuente.
- **GitHub Pages:** publicación gratuita del sitio web.

## ✨ Características

## 🚀 Publicación con GitHub Pages

El sitio se publica mediante GitHub Pages desde un repositorio público.

Configuración de publicación:

- **Rama:** `main`.
- **Carpeta:** `/(root)`.
- **Archivo principal:** `index.html`.

Los cambios realizados en el repositorio se publican después de que GitHub Pages completa el proceso de despliegue.

## ✅ Verificación de requisitos

- **R12 — Repositorio público:** el código fuente está disponible en un repositorio público de GitHub.
- **R13 — Sitio publicado:** la página está publicada mediante GitHub Pages y se debe comprobar su funcionamiento desde computadores y celulares.
- **R14 — Enlaces e imágenes:** se deben verificar los enlaces entre las páginas, la carga de la fotografía y los recursos gráficos en el sitio publicado.
