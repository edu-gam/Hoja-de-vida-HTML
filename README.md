## 📂 Estructura del proyecto

- `index.html`: página principal con la hoja de vida.
- `proyectos.html`: página con los proyectos personales.
- `contacto.html`: página con la información de contacto.
- `styles.css`: estilos visuales y adaptación a diferentes tamaños de pantalla.
- `img/`: carpeta con la fotografía de perfil y otros recursos gráficos.
- `mockup/`: capturas del mockup y evidencias visuales del funcionamiento del sitio.
- `capturas/`: capturas de funcionamiento de la página en celular y computador.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño, colores, tipografía, distribución y adaptación a diferentes pantallas.
- **Git:** control de versiones del proyecto.
- **GitHub:** almacenamiento del código fuente.
- **GitHub Pages:** publicación gratuita del sitio web.

## ✨ Características

- Presentación del perfil personal y profesional.
- Secciones de formación académica, habilidades y experiencia laboral.
- Página independiente para proyectos.
- Página de contacto.
- Fotografía de perfil.
- Menú de navegación entre páginas.
- Diseño adaptable a computadores y celulares.
- Efectos visuales en las tarjetas de proyectos.

## 🚀 Publicación con GitHub Pages

El sitio se publica mediante GitHub Pages desde un repositorio público.

Configuración de publicación:

- **Rama:** `main`.
- **Carpeta:** `/(root)`.
- **Archivo principal:** `index.html`.

Los cambios realizados en el repositorio se publican después de que GitHub Pages completa el proceso de despliegue.

## ✅ Verificación de requisitos

- **R12 — Repositorio público:** el código fuente está disponible en un repositorio público de GitHub.
- **R13 — Sitio publicado:** la página está publicada mediante GitHub Pages y se debe comprobar su funcionamiento desde computadores y celulares.
- **R14 — Enlaces e imágenes:** se deben verificar los enlaces entre las páginas, la carga de la fotografía y los recursos gráficos en el sitio publicado.
